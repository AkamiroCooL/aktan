# Нарезка стрима на клипы

Инструмент: `clipper/stream_clipper.py` (нужны ffmpeg, ffprobe и `pip install yt-dlp`).

1. Проверь `which ffmpeg ffprobe` и `python3 -m yt_dlp --version`; если нет — установи.
2. Если стрим длинный, сначала режь отрезок через `--start/--end`, чтобы не качать часы видео.
3. Запусти:
   `python3 clipper/stream_clipper.py "<ссылка или файл>" --start <MM:SS> --end <MM:SS> --count <N> --min 10 --max 15 --out clips`
   Для конкретных моментов вместо автопоиска передай `--at <таймкод>` (можно несколько раз).
4. Покажи пользователю список клипов с таймкодами из вывода скрипта.

Ограничения: идущая трансляция скачивается только после окончания эфира;
в облачных сессиях с ограниченной сетью YouTube может быть недоступен —
тогда запускай на компьютере пользователя.
